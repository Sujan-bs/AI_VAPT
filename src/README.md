# AI-VAPT (AI-Based Vulnerability Assessment & Reporting Tool)

AI-VAPT is an automated vulnerability assessment and penetration testing (VAPT) reporting tool that performs:

- Network scanning using Nmap
- Web checks using Curl
- Web vulnerability scanning using Nuclei
- Automated website screenshots using Playwright
- AI-generated Executive Summary using Ollama (Llama3)
- Professional PDF report generation using ReportLab

---

## Features

✅ Accepts both **IP Address** and **Domain**  
✅ Auto-resolves domain → IP  
✅ Detects HTTP/HTTPS services automatically  
✅ Runs Nmap scan (Top 1000 ports)  
✅ Runs Nuclei fast scan with limited templates  
✅ Takes website screenshots  
✅ Generates a professional multi-page PDF report  
✅ Includes AI Executive Summary and recommendations

---

## Tools Used

- Nmap
- Curl
- Nuclei
- Playwright
- ReportLab
- Ollama (Llama3)
